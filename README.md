PHẦN 1: Phân tích
- Chức năng: đăng ký bệnh nhân, khám bệnh, cập nhật bệnh án, in báo cáo.
- Phi chức năng: bảo mật, phân quyền, mã hóa, Audit Log, sao lưu.

PHẦN 2: Triển khai
Clinic-Cloud tích hợp hồ sơ điện tử, Excel quản lý dữ liệu chuẩn Database Mindset và Dashboard Donut Chart.

PHẦN 3: Kiểm thử
Nếu gán nhầm Heading, dùng Ctrl + Shift + N để trở về Normal.

Bẫy dữ liệu:
Không xóa dòng vì ô trống và không chèn dòng trống giữa bảng để AutoFilter không bị ngắt quãng.
